Degree Objectives - UAT

  • Apply the principles of UX/UI design to user-centered experiences.
  • Develop interactive media using modern web technologies.
  • Design and build responsive websites using HTML, CSS, and JavaScript.
  • Demonstrate proficiency in digital media creation and editing tools.
  • Collaborate effectively in team-based development environments.

These objectives represent the core skills developed in the UAT program, focusing on creativity, technical ability, and real-world application.
